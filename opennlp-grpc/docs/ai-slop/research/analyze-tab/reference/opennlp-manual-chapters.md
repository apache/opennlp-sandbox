Terminology confirmed in the manual body: "Sentence Detector", "Name Finder"
(the chapter's own section is titled "Named Entity Recognition"), "Document
Categorizer", "Chunker", "Chunking", "Tokenization", "Tagging".

Note for the workbench: OpenNLP's "Chunker"/"Chunking" means shallow syntactic
parsing (noun-phrase and verb-phrase chunks). It does not mean splitting a
document into passages for retrieval. See `elastic-chunking-settings.md` for the
retrieval sense of the same word.
