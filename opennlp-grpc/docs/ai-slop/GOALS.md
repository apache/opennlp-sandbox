# Workbench goals, phased

The per-theme lists under `research/<theme>/goals/goals.md` hold every item.
This file orders them into goals that can each be one pull request, with
acceptance criteria. Order is by dependency: the shared vocabulary and the
test gates first, the shared mechanisms second, then one goal per tab.

Rules for every phase: red test before the fix; no em dashes; javadoc on
every new method; strings that the vitest snapshot covers change in the same
commit as the snapshot; the reactor stays green (`mvn clean verify` from the
reactor root) and `npm test` in `opennlp-grpc-webapp-default` passes.

## Phase 1: foundation

One PR. Everything here touches every tab and must land exactly once.

Status 2026-08-28: landed. Terminology pass with the retired-vocabulary vitest;
proto vocabulary vitest and the request-fixture round trip through the gateway
parser (the static service validators are still to be wired into that test);
ordinal sentiment polarity; scaled `index-documents` deadline; gateway idle
interval raised with a one-shot front-end retry; `flat_float` persists and
restores. `FlatFloatIndex.write/read` lives upstream in opennlp-embeddings.

1. Terminology, one commit: the decision table in
   `research/industry-terminology/README.md`, P1 rows. Adds a vitest that
   snapshots every user-visible string against that table.
2. Contract gate: vitest checking FE enum literals and `api.ts` keys against
   `opennlp-grpc-v1.protobin`; request fixtures generated by the real FE
   builders and parsed by `GrpcJsonApi.handle` plus the static service
   validators in a gateway JUnit test (`research/test-coverage/goals`).
3. Live bugs: ordinal sentiment polarity; `index-documents` deadline scaled by
   input size; gateway keep-alive idle interval raised and the FE retries a
   search once on `TypeError`; `flat_float` declares PERSISTENT and round-trips
   through checkpoint and read-only.

Accept when: the snapshot test lists no "workspace", "dynamic", "checkpoint",
"seal", "drift", "projection", "X-ray", "shape" or "bundle" string; a misspelled
enum in `api.ts` fails `npm test`; a one-star sentence renders negative; a POST
after a 35 s idle succeeds against the gateway; Save to disk works on a default
live index.

## Phase 3: one goal per tab, in navigation order

Each is one PR: help callout, empty states, jumps, tags, remaining P1 and P2
items from that theme's `goals/goals.md`, and the tab's e2e spec.

Status 2026-08-28: landed as one commit per tab. Every tab now has a help
callout, an empty state that names where its first object comes from, and
jumps at each dead end the audits listed.

Status 2026-08-29: the items left over from the tab commits landed as four
more: `ListVocabularies` behind the Trainer and Lifecycle pickers, the
In memory / Saved to disk / Read-only labels on both index pickers,
`POST /api/v1/analyze-protobuf` behind Download .pb for replies past the
browser limit, and Playwright specs for Models & data, Trainer and
Lifecycle. Every tab now meets the acceptance line below.

1. Analyze (`research/analyze-tab/goals`): add-to-index feedback, open-hit
   switch, size threshold shared by JSON view, copy and download, layer titles
   from `identity.standard`.
2. Build index (`research/workflows-tab/goals`): state-driven badges, degraded
   analyze-and-index mode, sample corpus, how-to callout, Lifecycle refresh.
3. Corpus search (`research/corpus-search-tab/goals`): missing-index and
   missing-add-on messages, components-gated advanced search, hybrid said once.
4. Live index search (`research/workspace-search-tab/goals`): first-run empty
   state, "What is a live index?", delete confirmation, user-named indexes,
   state chips.
5. Models & data (`research/models-and-data-tab/goals`): browned-out cards when
   installs are disabled, unlock and format tags, `name-finder` label, inbound
   and outbound jumps, restart banner.
6. Trainer (`research/trainer-tab/goals`): two gating states, Distill wording,
   three vocabularies defined, license and language on the descriptor, tags.
7. Lifecycle (`research/lifecycle-tab/goals`): empty state with jumps,
   collection definition, coverage flyout and "not measured", read-only indexes
   stay listed, dictionary picker, `ListVocabularies`.

Accept per tab when: the tab has a help callout, no dead end without a jump,
its `goals.md` P1 items are checked, and an e2e spec exercises its primary
action.

## Phase 4: model export

One PR after phase 2 (needs the descriptor fields): `opennlp-model.json`
beside every trained and installed model, `opennlp-catalog.json` emitted from
`StandardModelCatalog` and diffed in a test, then `FileModelCatalogProvider`
reading a pinned, signed index (`research/models-and-data-tab/goals`,
`research/trainer-tab/goals`).

Accept when: a model distilled on one server can be imported as a catalog
entry on another with its license, language and teacher recorded.
