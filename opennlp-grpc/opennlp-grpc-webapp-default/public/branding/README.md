# Apache OpenNLP branding assets

Derived from the official Apache OpenNLP logo published at
<https://www.apache.org/logos/res/opennlp/> (author: Bruno P. Kinoshita).

- `opennlp-logo.png`: the unmodified wide logo (`default.png`, 720x277,
  transparent background).
- `opennlp-mark.png`: the feather-and-book mark cropped square from
  `opennlp_highres.png` for the header chip; the favicon and touch icon at the
  `public/` root are downscaled renders of the same crop. Colors are unaltered.
