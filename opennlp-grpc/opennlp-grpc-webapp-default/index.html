Verified resource installer

Download before server startup

The server CLI accepts an operator-approved HTTP(S) or file URI and requires a SHA-256 or SHA-512 digest. Downloads are bounded, verified, staged, and installed atomically. 

java -jar opennlp-grpc-server.jar install-resource \
  --source https://example.invalid/resource.bin \
  --checksum <sha256-or-sha512> \
  --target /srv/opennlp/models

Configure the installed paths, then restart the server to load the new capabilities.
